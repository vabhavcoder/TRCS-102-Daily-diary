# Day 01 – Introduction to Cybersecurity

## Objective
Understand the purpose, importance and major domains of cybersecurity.

## Introduction
Cybersecurity is the practice of protecting computer systems, networks, applications and information against unauthorized access, disruption, modification and destruction. It combines technical controls, security policies and user awareness.

## Topics Covered

| Domain | Description |
|---|---|
| Network security | Protects network infrastructure and communications. |
| Application security | Identifies and reduces weaknesses in software. |
| Information security | Protects sensitive information from unauthorized disclosure or alteration. |
| Endpoint security | Protects computers and other connected devices. |
| Cloud security | Protects cloud-hosted services, workloads and data. |
| Digital forensics | Examines digital evidence related to security incidents. |

## Basic Security Terminology
- **Asset:** Something valuable, such as a computer or database.
- **Threat:** A potential cause of harm.
- **Vulnerability:** A weakness that could be exploited.
- **Risk:** The potential for loss arising from a threat exploiting a weakness.
- **Security control:** A measure that reduces security risk.

## Practical Activity – Basic Risk Assessment
Identify assets and possible weaknesses on a personally owned computer. The following table is an illustrative assessment, not a record of observed findings.

| Asset | Example risk | Recommended control |
|---|---|---|
| User account | Weak password | Unique password and MFA |
| Personal files | Data loss | Regular backups |
| Operating system | Unpatched software | Security updates |
| Network | Unauthorized access | Secure Wi-Fi configuration |

Add actual observations and screenshots of the security settings reviewed. Do not expose passwords or personal information.

## Learning Outcomes
- Explain the importance and major domains of cybersecurity.
- Differentiate threats, vulnerabilities and risks.
- Identify suitable basic security controls.

---

## Conclusion
Cybersecurity requires both preventive controls and continuous awareness. Risk assessment helps determine which assets require protection and which controls are appropriate.
